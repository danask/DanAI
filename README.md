# Project Instructions

## Running the Server

To start the server, execute the following command:

```bash
./start.sh
```

This command will run the server in development mode with live reloading.

## Requirements

Before running the server, make sure you have the following:

- Python 3.8+
- Docker (Optional for containerized environment)

## Usage

- Use `./start.sh` to run the server locally.
- The `/logs` endpoint can be accessed to retrieve logs.

## Additional Information

- The project is structured using FastAPI and MongoDB.
- The `start.sh` script is located in the root directory and should be executed to start the server.
